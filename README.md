# vibeflow-player.github.io

VibeFlow 官方法律文档站点（Privacy Policy & Terms of Service），通过 GitHub Pages 托管。

访问地址：<https://vibeflow-player.github.io>

## 目录结构

```
├── index.html     # 文档入口
├── privacy.html   # 隐私政策
├── terms.html     # 服务条款
└── style.css      # 样式
```

## 关于数据收集

VibeFlow App 不含任何分析、广告或追踪 SDK，不收集用户个人数据。
隐私政策内容依据 VibeFlow iOS 项目（`com.musicplayer.vibeflow`）的实际依赖与行为编写。

> 注：无 `app-ads.txt`，因为 App 未接入 AdMob。
